# OG Image Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create `src/app/opengraph-image.tsx` — a single, site-wide Open Graph image using the Kakaw AI design system (dark warm gradient, Newsreader italic headline, mascot PNG).

**Architecture:** One file using Next.js's `opengraph-image` file convention with `ImageResponse` from `next/og`. The font is committed as a TTF to avoid runtime network calls (ImageResponse does not support woff2). The mascot is read from disk at generation time and passed as a base64 data URL.

**Tech Stack:** `next/og` (`ImageResponse`), Node.js `fs/promises` + `path`, Newsreader Italic TTF (committed to `public/fonts/`)

---

### Task 1: Download and commit the Newsreader Italic font

**Files:**
- Create: `public/fonts/Newsreader-Italic.ttf`

`ImageResponse` (backed by Satori) supports only `ttf`, `otf`, and `woff` — **not woff2**. Download the TTF from Google Fonts and commit it so generation has no network dependency.

- [ ] **Step 1: Download the font**

```bash
mkdir -p public/fonts
curl -L "https://fonts.gstatic.com/s/newsreader/v20/cY9qfjOCX1hbuyalUrK49dLioYsn.woff" \
  -o public/fonts/Newsreader-Italic.woff
```

> **Note:** If the above URL is stale or returns an error, get the current URL by fetching:
> `https://fonts.googleapis.com/css2?family=Newsreader:ital,opsz,wght@1,6..72,400&display=block`
> Find the `src: url(...)` line and download that file. Save it as `Newsreader-Italic.woff` (woff is supported by Satori).

- [ ] **Step 2: Verify the file exists and is non-empty**

```bash
ls -lh public/fonts/Newsreader-Italic.woff
```

Expected: file present, size > 10KB.

- [ ] **Step 3: Commit**

```bash
git add public/fonts/Newsreader-Italic.woff
git commit -m "feat: add Newsreader Italic font for OG image generation"
```

### Task 2: Create the OG image component

**Files:**
- Create: `src/app/opengraph-image.tsx`

- [ ] **Step 1: Create the file**

```tsx
// src/app/opengraph-image.tsx
import { ImageResponse } from "next/og";
import { readFile } from "node:fs/promises";
import { join } from "node:path";

export const alt = "Kakaw AI — Talk to Your Database Like You Talk to a Friend";

export const size = {
  width: 1200,
  height: 630,
};

export const contentType = "image/png";

export default async function Image() {
  const [fontData, mascotData] = await Promise.all([
    readFile(join(process.cwd(), "public/fonts/Newsreader-Italic.woff")),
    readFile(join(process.cwd(), "public/mascot.png"), "base64"),
  ]);

  const mascotSrc = `data:image/png;base64,${mascotData}`;

  return new ImageResponse(
    (
      <div
        style={{
          width: "100%",
          height: "100%",
          display: "flex",
          background: "linear-gradient(135deg, #705731 0%, #291800 100%)",
          alignItems: "center",
          padding: "0 80px",
          gap: 0,
        }}
      >
        {/* ── Left panel ── */}
        <div
          style={{
            flex: 1,
            display: "flex",
            flexDirection: "column",
            justifyContent: "center",
            paddingRight: 60,
          }}
        >
          {/* Eyebrow */}
          <div
            style={{
              display: "flex",
              fontFamily: "sans-serif",
              fontSize: 16,
              fontWeight: 700,
              letterSpacing: "0.2em",
              textTransform: "uppercase",
              color: "#e3c193",
              marginBottom: 20,
            }}
          >
            KAKAW AI
          </div>

          {/* Headline */}
          <div
            style={{
              display: "flex",
              fontFamily: "Newsreader",
              fontSize: 72,
              fontStyle: "italic",
              fontWeight: 400,
              color: "#fffaf8",
              lineHeight: 1.15,
              marginBottom: 24,
            }}
          >
            Talk to your database like a friend.
          </div>

          {/* Body copy */}
          <div
            style={{
              display: "flex",
              fontFamily: "sans-serif",
              fontSize: 22,
              color: "rgba(255, 250, 248, 0.65)",
              lineHeight: 1.5,
              marginBottom: 40,
            }}
          >
            No SQL needed. Ask in plain English, get answers in seconds.
          </div>

          {/* Wordmark row */}
          <div
            style={{
              display: "flex",
              alignItems: "center",
              gap: 16,
            }}
          >
            <div
              style={{
                width: 40,
                height: 2,
                background: "#e3c193",
                borderRadius: 1,
              }}
            />
            <div
              style={{
                display: "flex",
                fontFamily: "Newsreader",
                fontStyle: "italic",
                fontSize: 26,
                fontWeight: 400,
                color: "#e3c193",
              }}
            >
              kakaw.ai
            </div>
          </div>
        </div>

        {/* ── Right panel ── */}
        <div
          style={{
            width: 320,
            display: "flex",
            alignItems: "center",
            justifyContent: "center",
            position: "relative",
          }}
        >
          {/* Orbit bubble 1 */}
          <div
            style={{
              position: "absolute",
              width: 120,
              height: 120,
              borderRadius: "50%",
              background: "rgba(227, 193, 147, 0.10)",
              top: -30,
              right: -30,
            }}
          />
          {/* Orbit bubble 2 */}
          <div
            style={{
              position: "absolute",
              width: 80,
              height: 80,
              borderRadius: "50%",
              background: "rgba(227, 193, 147, 0.07)",
              bottom: -20,
              left: -20,
            }}
          />

          {/* Mascot circle */}
          <div
            style={{
              display: "flex",
              width: 280,
              height: 280,
              borderRadius: "50%",
              background: "rgba(255, 255, 255, 0.08)",
              border: "1px solid rgba(255, 255, 255, 0.15)",
              alignItems: "center",
              justifyContent: "center",
              overflow: "hidden",
            }}
          >
            <img
              src={mascotSrc}
              width={220}
              height={220}
              style={{ objectFit: "contain" }}
            />
          </div>

          {/* Pill badge */}
          <div
            style={{
              display: "flex",
              position: "absolute",
              bottom: 20,
              right: -10,
              background: "rgba(255, 255, 255, 0.10)",
              border: "1px solid rgba(255, 255, 255, 0.20)",
              borderRadius: 999,
              padding: "8px 18px",
              fontFamily: "sans-serif",
              fontSize: 14,
              color: "rgba(255, 250, 248, 0.85)",
            }}
          >
            ✦ No SQL required
          </div>
        </div>
      </div>
    ),
    {
      ...size,
      fonts: [
        {
          name: "Newsreader",
          data: fontData,
          style: "italic",
          weight: 400,
        },
      ],
    }
  );
}
```
