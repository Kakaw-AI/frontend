An answer has up to four parts.

## The answer

A short summary of what the result shows: the headline finding and a few highlights. It doesn't repeat the table; the table is right below it.

## The table

The rows the query returned, up to 200. Sort by a column with its header, and use **Download CSV** to take the rows into a spreadsheet.

If a query would return more than 200 rows, the table shows the first 200. Ask a narrower question, or ask for totals, to see the whole picture.

When you ask to chart an answer you already have (*"show that as a bar chart"*) and the rows are the same as a table above, the new table starts folded under the chart. Choose **Show table** to open it.

## The chart

Kakaw draws a chart when the result suits one, such as a value over time or a comparison across categories, and always when you ask for one (*"as a bar chart"*, *"chart that"*).

### Supported chart types

| Type | Good for | The result needs | Ask with |
| --- | --- | --- | --- |
| Bar | Comparing a few categories | A text column and a measure. The top 12 bars; the rest are added up as *Other categories*. | *"bar chart"*, *"column chart"*, *"as bars"* |
| Grouped or stacked bar | Categories split by a second text column | Two text columns and a measure. The top 12 categories and top 6 series; the rest are added up as *Other*. | *"bar chart by channel"*, add *"stacked"* to stack them |
| Horizontal bar | Rankings and long names | A text column and a measure. Up to 25 bars, largest first. | *"horizontal bar chart"* |
| Line | A value over time | A date or period column and a measure. With a second text column, one line each, up to 6. | *"line chart"*, *"as a line"* |
| Donut (pie) | Shares of a whole | 8 or fewer rows, none negative. | *"pie chart"*, *"donut chart"*, *"as a pie"* |
| Combo | Two measures for the same categories | A category column and two measures. Bars for the first, a line for the second, each on its own axis. Up to 24 rows. | *"combo chart"* |
| Scatter | How two measures relate | Two measures. Up to 100 points, with a dashed trend line. | *"scatter plot"* |
| Bubble | Three measures at once | Three measures: two on the axes, the third as bubble size. | *"bubble chart"* |
| Heatmap | Two categories crossed, such as country by product | Two text columns and a measure. Up to 30 columns and 25 rows; deeper colour is a higher value. | *"heatmap"* |
| Histogram | How one measure is spread | One measure, grouped into about 20 ranges. Up to 100 values. | *"histogram"* |

When you name a type, Kakaw draws that type whenever the result has what the table lists. If it doesn't, for example a pie of 23 categories, Kakaw picks the closest type that fits.

### When you don't name a type

Without a named type, Kakaw picks one from the shape of the table:

- A value over time gets a line with a shaded area. With a second text column, such as a channel, each value of that column gets its own line (up to 6).
- Two measures per row, such as revenue and order count, get a combo chart: bars for the first and a line for the second, each on its own axis.
- Three or more measures per row, with at least 4 rows, get a bubble chart: two measures on the axes, the third as bubble size, the top rows labelled, and a dashed trend line.
- Two text columns and a measure get grouped bars when there are at most 12 categories and 6 series, and a heatmap when there are more.
- One measure per category gets ranked horizontal bars when there are more than 6 rows or long names, and columns otherwise. A question about share or percentage with 8 or fewer rows gets a donut.

Columns named like ids (`customer_id`) are never charted as measures, and whole-number year, quarter, month or week columns are used as the time axis. Hover over a bar, point or cell to see its exact values. Use **Download SVG** to save the chart as an image, or **Download CSV** for its data.

When you ask for a chart the data can't support, Kakaw says why and shows what it can.

## The query

**Show SQL** reveals the exact query that ran on PostgreSQL or SQLite. For a MongoDB database the button reads **Show query** and shows the collection and aggregation pipeline as JSON. Copy it to run it yourself or to check how a number was counted.

## Sources

When the answer used the web, a **Web sources** list follows, numbered to match the `[1]`, `[2]` marks in the answer, and **Used Web Search** appears next to the token count. See [Web search](/docs/web-search).

## Token count

Under each answer, the time and the number of tokens the answer used across all its model calls. Your provider bills by tokens. Your profile adds them up per model. See [Your profile and usage](/docs/chat/controls#your-profile-and-usage).
