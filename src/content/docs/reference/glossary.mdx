---
title: Glossary
description: The words these docs use.
---

**Answer.** Kakaw's reply to a question: a summary, and with it the result table, a chart, the SQL and any web sources.

**Database.** A data source you connected: a PostgreSQL or MongoDB database, or an uploaded SQLite file. Each chat belongs to one.

**Model.** A saved connection to a language model: the provider, the model id and the key or address. Each chat uses one at a time.

**OpenAI-compatible.** Any service that accepts requests in the OpenAI API format: OpenAI itself, OpenRouter, Ollama, LM Studio and many others.

**Read-only.** A query that can only read data. Kakaw runs nothing else.

**Remembered question.** A question a database answered, kept with the SQL that worked, so similar questions start from it.

**Review.** The quick check after a query runs: does the result answer the question, and is the data enough or does Kakaw need the web too?

**Schema.** The structure of a database: its tables, columns, keys and indexes.

**Sync.** Reading a database's schema and sample values when it is connected.

**Think.** The toggle that lets a reasoning model think at length before writing the SQL.

**Token.** The unit model providers bill by. Each answer shows how many it used.

**Web sources.** The pages an answer cited, numbered to match `[1]`, `[2]` in the text.
