# Getting Started

Get from zero to your first insight in under 5 minutes.

## Prerequisites

- A running database (Postgres, MySQL, Snowflake, or SQLite)
- An API key from one of: Anthropic, OpenAI, Gemini, Ollama, or LM Studio

## Step 1: Create an account

Go to the [Kakaw AI app](/login) and sign up with your email. No credit card required.

## Step 2: Connect your database

After signing in you'll land in the onboarding flow. See [Connect a Database](/docs/connect-database) for detailed instructions.

## Step 3: Add your LLM key

Choose your preferred AI provider and paste your API key. See [Set Up Your LLM](/docs/setup-llm) for all supported providers.

## Step 4: Ask your first question

Head to the Chat and type a question like:

> "How many orders were placed last month?"

Kakaw will translate this into SQL, run it against your database, and return an answer — along with the SQL it used, so you can verify the result.

- [Using the Chat](/docs/using-chat) — tips for more complex queries
