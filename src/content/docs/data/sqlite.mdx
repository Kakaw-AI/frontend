## The file

- Extensions: `.db`, `.sqlite` or `.sqlite3`.
- Size: up to 25 MB.

## Upload

1. Choose **SQLite** and drop the file, or click to pick it.
2. Give it a name if you like, such as *Sales export*.
3. Choose **Upload and connect**. The file goes straight from your browser to Kakaw's storage, then Kakaw reads its schema. See [Schema sync](/docs/data/schema-sync).

<Callout type="warn" title="Kakaw keeps the file">
To run your queries, Kakaw stores a copy of the uploaded file. Upload a copy you are fine storing, and leave out tables you don't want to ask about. Deleting the database in Kakaw deletes the stored file.
</Callout>

## Queries on the file

Queries open the file read-only, in a separate process that is stopped if a query runs longer than 30 seconds.

## Changing the data

An uploaded file is a snapshot. To ask about newer data, upload the new file as another database.
