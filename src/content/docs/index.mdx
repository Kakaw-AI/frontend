Kakaw turns a question like *"which products sold best last quarter?"* into a read-only query, runs it on your database, checks that the result answers the question, and explains it. You see the answer, the table it came from, a chart when one helps, and the query itself: SQL for PostgreSQL and SQLite, an aggregation pipeline for MongoDB.

You bring two things: a database and a model. Kakaw does the rest.

## Using these docs with an AI assistant

Every page has a **Copy Markdown** button and an **Open** menu for ChatGPT and Claude. Assistants and agents can read the docs directly:

- `/llms.txt`: an index of every page.
- `/llms-full.txt`: all pages in one file.
- Any page with `.md` added, like [`/docs/quickstart.md`](/docs/quickstart.md).
- Any page URL requested with the header `Accept: text/markdown`.
