I've analyzed the transactional records for the last two quarters. The following SQL query was executed to aggregate the results from the `order_items` and `products` tables.

SQL Query 
SELECT 
    p.name, 
    SUM(oi.price * oi.quantity) AS q4_revenue,
    ((SUM(oi.price * oi.quantity) - q3.revenue) / q3.revenue) * 100 AS growth_pct
FROM products p
JOIN order_items oi ON p.id = oi.product_id
JOIN (
    SELECT product_id, SUM(price * quantity) AS revenue 
    FROM order_items 
    WHERE date BETWEEN '2023-07-01' AND '2023-09-30'
    GROUP BY product_id
) q3 ON p.id = q3.product_id
WHERE oi.date BETWEEN '2023-10-01' AND '2023-12-31'
GROUP BY p.name, q3.revenue
ORDER BY q4_revenue DESC
LIMIT 5;
